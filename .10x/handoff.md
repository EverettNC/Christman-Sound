# Handoff — voice-system

Every lane reads ADR-001 first. It holds the file ownership, the shared contract and Everett's rulings.

When a lane finishes:
- Add its entry to .10x/decisions/sde/voice-system.md: what was built, the PRs with their hashes, the tests, and anything it deviated from.
- Add a line to status.md.
- Do both in the lane's last PR.

Any change to a field name or a keyword goes through the orchestrator (the main session), never straight from one lane to another.
